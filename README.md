# Slimy Suite

**Create. Focus. Flow.**

讓想法有地方落腳，讓每一天更有條理。

Slimy Suite 是一套為 Windows 打造的桌面工具組合，包含 **Slimy To Do** 與 **Slimy Note** 兩款可獨立使用的應用程式。從整理待辦、安排專注時間，到記錄靈感、撰寫文件與編輯程式碼，都能在簡潔舒適的介面中完成。

## 兩款工具，一種順暢的工作節奏

### Slimy To Do — Premium Task Manager

把繁雜的待辦事項，整理成清楚可執行的計畫。

- **任務管理**：新增、編輯、分類與完成待辦事項。
- **進度掌握**：查看任務完成情況，聚焦重要事項。
- **Focus Timer**：自訂專注與休息時間，建立適合自己的工作節奏。
- **資料管理**：支援 JSON／CSV 匯入匯出及備份。
- **個人化介面**：依喜好調整主題與部分顯示設定。

不論是日常生活、課業安排，還是個人專案，都能用更輕鬆的方式保持井然有序。

### Slimy Note — Advanced Notes & Code Editor

讓筆記、文件與程式碼，都擁有自己的創作空間。

- **多分頁編輯**：在不同文件之間快速切換。
- **程式碼語法高亮**：閱讀與編輯多種程式語言更加清楚。
- **Markdown 支援**：撰寫筆記並查看預覽。
- **獨立檔案總管**：需要時開啟，讓編輯畫面保持寬敞。
- **HTML 預覽**：查看網頁內容的呈現效果。
- **程式執行面板**：在編輯環境中查看程式輸出。
- **Home／Office 模式**：依個人或工作用途調整使用空間。

從快速記錄一個想法，到專心編輯一份完整的程式專案，Slimy Note 都能陪你持續創作。

## 簡潔，但不單調

Slimy Suite 採用柔和的薄荷綠品牌色、深色介面、圓角元件與清晰的視覺層次。圖示以繪製方式呈現，不依賴表情符號，讓整體操作體驗更一致。

兩款應用程式皆提供個人化設定，讓工具配合你的習慣，而不是讓你遷就工具。

## 從規劃到完成

**01｜整理計畫**  使用 Slimy To Do 建立任務，掌握待辦與完成進度。

**02｜專注投入**  透過可自訂的 Focus Timer，安排適合自己的專注節奏。

**03｜自由創作**  開啟 Slimy Note，記錄靈感、整理文件或撰寫程式碼。

## 適合誰使用？

Slimy Suite 適合希望整理日常事務的使用者、學生、創作者、辦公工作者，以及需要輕量文字與程式碼編輯工具的人。

## 開始使用 Slimy Suite

兩款應用程式可以依需求分別使用，也可以搭配成完整的工作流程。目前提供專案 ZIP 檔案；可直接安裝的 Windows 版本尚未提供。
